# XMemo Capabilities Matrix

This document provides a public capability matrix for XMemo based on documented and verified features. Every entry is linked to its authoritative documentation page and dated to prevent documentation drift.

The canonical and complete documentation is hosted at [https://docs.xmemo.dev/](https://docs.xmemo.dev/). Dynamic details such as rate limits, account quotas, lifetimes, item caps, and client bundles are maintained on the documentation site rather than mirrored here.

---
